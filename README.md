# -LILLYS_HOME_STAY

Official website repository for **The Lillys Homestay Alleppey (Alappuzha, Kerala)**.

## 🌿 Overview
The Lillys Homestay is an authentic Kerala homestay located in the heart of Alleppey's backwaters. This multi-page website provides guests with an immersive preview of the homestay experience, ayurvedic wellness therapies, curated backwater adventures, photo galleries, and local travel directions.

## 📁 Website Pages
- **Home (`index.html`)**: Hero presentation, room highlights, Ayurvedic therapy cards, curated local activities, guest reviews, and direct WhatsApp / call bookings.
- **About Us (`about.html`)**: The story of Lillys Homestay, warm host hospitality, heritage, Ayurvedic treatments, and curated experiences.
- **Gallery (`gallery.html`)**: High-resolution 52-photo showcase categorized by Rooms, Homestay, Dining, Backwaters, and Experiences, complete with full-screen interactive lightbox.
- **Location Near (`location.html`)**: Proximity guide to 8 iconic Alleppey attractions (Alleppey Backwaters, Punnamada Lake, Alappuzha Beach, Lighthouse, Revi Karunakaran Museum, Coir Museum, Marari Beach, St. Andrew's Basilica) and transportation guide (Train, Air, Boat & Bus).
- **Contact (`contact.html`)**: Direct contact numbers, WhatsApp messaging, email, GPS coordinates, interactive Google Maps embed, and inquiry form.

## 🛠️ Tech Stack
- **HTML5 & CSS3**: Modern responsive layout, custom typography, backdrop blur filters, high-contrast accessible overlays.
- **Vanilla JavaScript**: Mobile navigation drawer, dynamic gallery filters, image modal lightbox, smooth scroll interactions.
- **Zero Heavy Dependencies**: Pure lightweight code optimized for fast mobile and desktop loading.

## 🚀 Running Locally
Open any `.html` file directly in a web browser, or run a local static server:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
